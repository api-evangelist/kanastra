# Kanastra Banking

> Kanastra is a Brazilian banking-as-a-service and private-credit infrastructure provider. The Kanastra Banking API covers financial accounts, PIX (keys, transfers, deposits, QR Codes / BR Code), boleto (bank slip) issuance with CNAB return files, TED transfers, wallets, commercial notes (CCB) with guarantees, and issuers. Authentication is a private_key_jwt (ES512 client-assertion) flow returning a scoped Bearer JWT.

## APIs
- [Kanastra Banking API docs](https://banking-docs.kanastra.com.br/): Public Postman-published reference (66 operations, 20 resource groups).
- Production base URL: https://banking.kanastra.com.br/api/v1
- Sandbox base URL: https://banking-sandbox.kanastra.com.br/api/v1
